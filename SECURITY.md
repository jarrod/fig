# Security

Fig is a static site: it runs entirely in your browser, with no server, accounts or stored data. Still, if you find a security problem, such as a way to run script through a shared link or an exported SVG, I'd like to hear about it.

## Reporting a problem

Please report it privately through [GitHub's vulnerability reporting](https://github.com/jarrod/fig/security/advisories/new) rather than opening a public issue. Include the steps to reproduce it and, if you can, a link or file that shows it.

I'll reply as soon as I can and keep you updated while it's fixed. Only the latest version on `main` is supported.
